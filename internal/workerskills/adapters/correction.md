## Correction role

Start from the controller's preserved failed test or review finding. Reproduce
the concrete bug with a focused regression that fails for the reported reason,
then make the smallest fix and show the regression passing. Preserve commands,
results, and the finding in authorized Task documentation or private output; the
controller's prior evidence remains immutable. Restore the intended behavior
without weakening acceptance. Rebuild the exact candidate output and return the
required structured answer for fresh controller acceptance and separate review.
Stay within the existing attempt limit. An unchanged failure or a speculative
workaround is not successful correction; report a concrete blocker if necessary.
