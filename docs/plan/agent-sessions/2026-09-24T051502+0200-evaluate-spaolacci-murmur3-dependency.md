### Source, API, and ordinary behavior

`Hash128`; seeded and unseeded 32-, 64-, and 128-bit constructors; and seeded
and unseeded one-shot sum functions. The concrete hashers implement the
applicable standard `hash.Hash`, `hash.Hash32`, and `hash.Hash64` contracts.
All three evaluated versions expose the same 89-line API at SHA-256
`e8babeba27838f683d9c8d535d6e1484f96b18462f1decc622b9dc86a470f09a`.

`Write` reads but does not mutate caller input, retains an owned copy only for
an incomplete tail, and returns `len(p), nil`. `Sum(b)` appends big-endian hash
bytes and may reuse caller-provided capacity under the standard hash contract;
the one-shot functions return values directly. `Reset` restores seed/state.
There are no resources, cleanup duties, lifecycle errors, or I/O boundaries.
Mutable hasher instances are not safe for unsynchronized concurrent use;
independent instances and one-shot calls can run concurrently when callers do
not mutate shared input. Results are deterministic for equal input and seed on
supported little-endian targets. The code uses native-endian unsafe word loads
and makes no cryptographic promise.
