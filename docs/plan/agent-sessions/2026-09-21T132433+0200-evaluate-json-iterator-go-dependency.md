## API And Ordinary Behavior

The root package exposes global default/compatible/fast configurations,
configuration freezing, marshal/unmarshal/get/valid helpers, iterator and
stream APIs/pools, encoder/decoder wrappers, `Any`, `RawMessage`, `Number`,
extensions, and custom type/field codecs. `extra` exposes binary-as-string,
fuzzy decoders, naming, private-field, and time-as-integer extensions. Decoder
`Token` remains documented as unfinished. `MarshalIndent` rejects nonempty
prefix or non-space indentation by panic, an explicit compatibility limit.

Configuration controls map sorting, HTML escaping, floating-point precision,
case sensitivity, unknown-field rejection, object reuse, raw-message
validation, and tag handling. Default map order is not deterministic;
`ConfigCompatibleWithStandardLibrary` sorts maps, while `ConfigFastest`
intentionally uses lossy six-digit floats. Ordinary fixtures confirmed struct,
map, interface, pointer, nil map/slice, raw message, custom codec, `UseNumber`,
validation/error, decoder, encoder, iterator, and stream behavior, including
finite-number rejection in v1.1.7 and later.

Streams own a mutable buffer that callers must treat as aliased; marshal copies
before returning. `ReadStringAsSlice` explicitly borrows iterator storage only
until the next call, while `SkipAndReturnBytes` copies. Pools reset observable
writer/error/attachment state but retain reusable buffers. There is no closeable
resource or external boundary. Reflection uses `modern-go/reflect2` and unsafe
pointers. Frozen operational caches and stream/iterator pools are suitable for
concurrent use, but global extension/type/field codec registries and config
extension slices mutate ordinary unprotected maps/slices. Registration must be
completed before concurrent use and cached codec state; this is an API/global-
state boundary, not evidence of concurrent registration safety.

No stable release passes every ordinary compatibility contract:

  json-iterator emits `"\\u0008\\u000c"`.

- Current master fixes the map-key divergence and passes Go 1.18.10, but it is
